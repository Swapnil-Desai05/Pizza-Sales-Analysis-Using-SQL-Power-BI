# Pizza Sales Analysis Using SQL & Power BI

## Project Overview
This project analyzes pizza sales data using SQL and Power BI to understand business performance and identify sales trends. SQL queries are used to calculate key metrics, analyze pizza categories, and identify the best- and worst-selling pizzas. Power BI is used to create interactive dashboards for visualizing the results.

## Objectives
- Analyze total revenue, orders, and pizzas sold.
- Calculate average order value and average pizzas per order.
- Identify the top 5 and bottom 5 pizzas by revenue, quantity, and total orders.
- Analyze daily and monthly order trends.
- Compare sales by pizza size and category.
- Identify the busiest days and months.

## Tools Used
- SQL / PostgreSQL
- Power BI
- DAX
- Power Query
- Excel

## Key Performance Indicators (KPIs)
- Total Revenue
- Average Order Value
- Total Pizzas Sold
- Total Orders
- Average Pizzas Per Order

## Dashboards
1. **Sales Overview:** Daily and monthly order trends, sales by pizza size, sales by category, and pizza category performance.
2. **Best & Worst Sellers:** Top 5 and bottom 5 pizzas by revenue, quantity, and total orders.

## Key Insights
- The Classic category has the highest sales volume among the categories shown.
- Large pizzas contribute the highest share of sales by pizza size.
- Friday has the highest daily order count in the displayed report.
- July has the highest monthly order count in the displayed report.
- The Thai Chicken Pizza is a top revenue contributor, while the Brie Carre Pizza is among the lowest performers in the displayed report.

## Business Value
The analysis helps businesses understand sales performance, identify popular products, recognize low-performing pizzas, and support data-driven decisions about inventory, promotions, and product strategy.
